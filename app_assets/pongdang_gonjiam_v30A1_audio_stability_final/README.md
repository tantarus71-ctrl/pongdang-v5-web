# 퐁당퐁당 곤지암천 v25R

리소스·디렉토리·index.html 경량화 안정본입니다.

## 핵심
- index.html은 진입점 역할만 유지
- CSS는 src/styles/main.css로 분리
- JS는 src/app.js로 분리
- assets는 bg/fish/icons/effects/audio 기준으로 정리
- docs에 개발기획서, 업데이트 규칙, 검증 체크리스트 포함
- MASTER_개발기획서_상시참조.txt를 이후 모든 작업의 최상위 기준으로 사용

## 실행
브라우저에서 index.html을 열거나 로컬 서버에서 실행합니다.

```bash
python3 -m http.server 8080
```
