# 퐁당퐁당 v4.8.36 시각 확인 프로토콜

기준 브랜치: feature/v4.8.36-top-brand-title

## 1. 목적

앞으로 모든 UI/레이아웃 변경은 코드 반영만 하지 않고, 사용자가 눈으로 확인할 수 있는 미리보기 기준을 함께 제공한다.

## 2. 기본 확인 대상

상단 로고 적용 후 반드시 확인할 화면은 다음이다.

1. `index.html` 기준 화면
2. `viewer.html` 기준 화면
3. 모바일 390px 폭 기준 화면
4. 모바일 430px 폭 기준 화면
5. 태블릿 세로 기준 화면
6. PC 브라우저 기준 화면

## 3. 확인 항목

### 3-1. 로고 크기

- `퐁당퐁당`이 충분히 크게 보이는가
- `곤지암천`이 작지만 또렷하게 보이는가
- 로고가 너무 높이를 많이 차지하지 않는가
- 로고가 앱 상단의 버튼이나 상태 요소를 가리지 않는가

### 3-2. 겹침 여부

- 기존 heroCard와 겹치는가
- 5존 버튼과 겹치는가
- 수조 화면을 과하게 가리는가
- 스마트폰 노치/상단 안전영역과 겹치는가

### 3-3. 어린이용 시각 기준

- 색이 밝고 친근한가
- 글자가 바로 읽히는가
- 너무 복잡하지 않은가
- 수중 앱 분위기와 맞는가

## 4. 앞으로의 작업 규칙

UI 변경이 있을 때마다 다음 중 하나를 반드시 만든다.

1. `preview/` 폴더 안에 확인용 HTML 생성
2. 모바일/PC 레이아웃 기준 문서 생성
3. 가능하면 이미지 캡처 또는 목업 이미지 첨부
4. 변경 전/후 차이를 개발 문서에 기록

## 5. v4.8.36 현재 적용 상태

현재 상단 로고는 `index.html`과 `viewer.html`에서 iframe wrapper 방식으로 적용되어 있다.

- 앱 본체: `app_assets/index.html`
- 로고 자산: `assets/brand/pongdang_gonjiam_logo_top_v4_8_36.svg`
- 적용 진입점: `index.html`, `viewer.html`

주의:

`app_assets/index.html`로 직접 들어가면 상단 로고 wrapper가 보이지 않는다. 최종 시연 확인은 `index.html` 또는 `viewer.html` 기준으로 한다.

## 6. 다음 보완 방향

눈으로 확인 후 아래 중 하나를 선택한다.

- 크기 유지
- 로고 5% 축소
- 로고 10% 축소
- 상단 위치 4px 아래로 조정
- 상단 위치 4px 위로 조정
- app_assets 본체에 직접 삽입하도록 구조 변경
