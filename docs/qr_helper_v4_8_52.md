# 퐁당퐁당 v4.8.52 QR 주소 생성 도우미 기록

작성 기준: 2026-04-26
저장소: tantarus71-ctrl/pongdang-v5-web
추가 페이지: app_assets/qr_helper_v4_8_52.html
QR 기준 경로: app_assets/start_v4_8_49.html

## 1. 목적

v4.8.52의 목적은 실제 배포 도메인이 확정된 뒤, QR 생성용 최종 주소와 외부 공유 문구를 빠르게 만들 수 있도록 돕는 페이지를 추가하는 것이다.

## 2. 추가 파일

```txt
app_assets/qr_helper_v4_8_52.html
```

이 페이지는 배포 도메인을 입력하면 다음 주소를 자동 생성한다.

```txt
https://배포도메인/app_assets/start_v4_8_49.html
```

## 3. 기능

- 배포 도메인 입력
- QR 생성용 최종 주소 자동 조합
- QR 주소 복사
- 시연 주소 새 창 열기
- 외부 공유 문구 자동 생성
- 공유 문구 복사
- 현장 확인 순서 표시
- 고정 경로 표시

## 4. 사용 방법

1. 배포 도메인을 입력한다.
2. `주소 만들기` 버튼을 누른다.
3. 생성된 QR 주소를 복사한다.
4. 복사한 주소로 QR 코드를 만든다.
5. 현장에서는 QR을 찍어 `/app_assets/start_v4_8_49.html`로 진입한다.

## 5. 확인 경로

QR 도우미:

```txt
/app_assets/qr_helper_v4_8_52.html
```

외부 안내 페이지:

```txt

```

안전 진입점:

```txt

```

검수 매트릭스:


## 6. QR 기준

QR 생성에는 반드시 아래 경로를 사용한다.

```txt
/app_assets/start_v4_8_49.html
```

`index.html` 직접 경로는 사용하지 않는다.
