## 1. 목적

v4.8.51은 외부 시연에 필요한 주소, QR 기준, 1분 시연 멘트, 현장 체크리스트를 한 문서로 고정하는 단계다.

기존 `app_assets/index.html`은 그대로 보존한다.

## 2. QR용 최종 주소 양식

배포 도메인이 정해지면 아래 형식으로 QR을 만든다.

```txt
https://배포도메인/app_assets/start_v4_8_49.html
```

예시:

```txt
https://example.netlify.app/app_assets/start_v4_8_49.html
```

QR 생성 기준은 반드시 `start_v4_8_49.html`을 사용한다.

이유:

- 기존 원본을 건드리지 않는다.
- 후보 실행본으로 자동 이동한다.
- 문제가 생겨도 원본 복구가 필요 없다.
- 외부 시연용으로 가장 안전하다.

## 4. 1분 시연 멘트

아래 멘트는 외부 설명용이다.

```txt
이 프로젝트는 곤지암천 생태계를 아이들이 직접 탐험하듯 볼 수 있게 만든 디지털 생태학습 수족관입니다.

핸드폰으로 QR을 찍으면 바로 물속 화면이 열리고, 아이들은 웃물·여울·잔여울·깊물·물모이 같은 우리말 구간을 눌러가며 민물고기를 관찰할 수 있습니다.

현재는 버들치를 기준 어종으로 넣어 두었고, 도감 버튼을 누르면 물고기 설명을 아이들 눈높이로 볼 수 있습니다.

중요한 점은 이 구조가 단순한 화면이 아니라, 앞으로 피라미·쉬리·각시붕어 같은 실제 곤지암천 어종과 희귀 물고기, 카메라 기반 관찰 기능까지 확장할 수 있는 경량화된 플랫폼 구조라는 점입니다.

기존 원본 파일은 보존하고, 오늘 시연은 검수된 안전 진입 링크로 보여드리겠습니다.
```

```txt
앞으로 실제 어종과 카메라 관찰 기능까지 확장할 수 있는 광주형 디지털 생태교육 모델입니다.
```

## 6. 현장 체크리스트

시연 전 아래 순서대로 확인한다.

1. 배포 주소가 열리는지 확인
2. `/app_assets/start_v4_8_49.html` 접속 확인
3. 후보 실행본으로 자동 이동되는지 확인
4. 핸드폰 세로 화면에서 수족관이 보이는지 확인
5. 하단 메뉴 4개가 보이는지 확인
6. 도감 버튼이 열리는지 확인
7. 버들치 카드가 보이는지 확인
8. 버들치 상세 모달이 열리는지 확인
9. 반짝 버튼이 열리는지 확인
10. 카메라 안내 버튼이 열리는지 확인
11. 현장 Wi-Fi 또는 데이터 연결 상태 확인
12. QR 코드가 카메라에서 잘 인식되는지 확인
13. 예비 링크를 문자 또는 카카오톡으로 보낼 수 있게 준비
14. 검수 매트릭스에서 모바일·태블릿·PC 상태 확인
