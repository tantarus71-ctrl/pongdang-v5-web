# 퐁당퐁당 v4.8.45 검수 결과 자동 수집 구조 기록

대상 파일:

- app_assets/test_matrix_v4_8_44.html

## 1. 목적

v4.8.45의 목적은 iframe 내부에서만 보이던 자가 점검 결과를 부모 검수 페이지가 자동으로 수집하도록 개선하는 것이다.

이제 핸드폰, 태블릿, PC 프레임의 통과 여부를 검수 페이지 상단에서 한 번에 볼 수 있다.

## 2. 변경 사항

### 2-1. 자가 점검 스크립트 개선

수정 파일:

```txt
app_assets/v4_8_40/js/pongdang-self-check.js
```

변경 내용:

- v4.8.45 점검 버전으로 갱신
- 점검 결과를 `window.parent.postMessage()`로 부모 페이지에 전달
- 전달 타입: `PONGDANG_SELF_CHECK_RESULT`
- 전달 데이터: DOM, 파일 경로, 렌더링 수, 이미지 상태, 배치 상태, 전체 통과 여부

### 2-2. 검수 매트릭스 개선

수정 파일:

```txt
app_assets/test_matrix_v4_8_44.html
```

변경 내용:

- 페이지 title을 v4.8.45로 갱신
- 상단 상태 대시보드 추가
- 핸드폰/태블릿/PC별 통과 상태 자동 표시
- iframe에서 전달된 점검 결과 수신
- 전체 통과 여부 자동 계산
