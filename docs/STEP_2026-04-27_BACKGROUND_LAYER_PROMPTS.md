## 4. 현재 레이어 구조 분석

현재 수족관 레이어 순서:

```text
z-index 0   .bg            실제 배경 이미지
z-index 2   .far-haze      먼 수중 안개
z-index 5   .godrays       햇빛/달빛 광선
z-index 7   .caustics      물결 반사
z-index 12  .eco-layer     돌, 수초 등 생태 오브젝트
z-index 30  .particles     부유 입자
z-index 38  .fish-layer    물고기
z-index 70+ bottom-card    하단 관찰 카드
z-index 76  zone-strip     존 선택
z-index 80  topbar         상단 메뉴
z-index 120+ panels        패널/팝업
```

레이어 충돌 방지 원칙:

- 배경 이미지는 `z-index 0`에서만 작동한다.
- 배경 이미지 안에는 강한 광선, 큰 부유 입자, 선명한 물고기, UI처럼 보이는 요소를 넣지 않는다.
- 광선은 `.godrays`, 물결 반사는 `.caustics`, 부유 입자는 `.particles`, 돌/수초 보강은 `.eco-layer`가 담당한다.
- 배경은 바닥 지형, 수심감, 원근, 물 색, 하천 분위기만 담당한다.
- 중앙 40~70% 영역은 물고기 유영 공간으로 비워 둔다.
- 상단 UI 영역과 하단 메뉴 영역에 핵심 생태 요소를 배치하지 않는다.
- 배경이 어두워져도 버튼, 카드, 물고기 클릭 영역을 방해하지 않아야 한다.

## 5. 배경 이미지 공통 제작 기준

공통 규격:

- 모바일 세로형 우선: 1080x1920 또는 1440x2560
- 태블릿/PC 대응을 위해 핵심 피사체는 중앙 세로축에 집중하지 말고 넓게 배치
- 실제 곤지암천 하천 느낌
- 어린이 생태학습용, 친근하지만 과장된 판타지 금지
- 너무 어둡거나 탁한 물 금지
- 3D 입체감은 앞/중/뒤 수심 레이어로 표현
- 배경에는 물고기 없음
- 배경에는 메뉴, 텍스트, 버튼, 캐릭터 없음
- 배경에는 강한 광선 없음. 자연스럽고 부드러운 빛 방향만 암시
- 부유 입자는 거의 없거나 아주 적게
- 중앙 유영 공간 확보
- 상단/하단 safe area가 가려도 배경 핵심이 살아야 함

공통 네거티브 프롬프트:

```text
no fish, no text, no logo, no UI, no button, no character mascot,
no fantasy glowing cave, no neon color, no muddy water, no dirty river,
no heavy particles, no strong bokeh, no dramatic sunbeam, no cartoon ocean,
no coral reef, no tropical sea, no aquarium glass reflection, no plastic toy style,
no clutter in center swimming area
```

## 9. 검증 체크리스트

- [ ] 10개 배경 파일이 기존 경로에 존재한다.
- [ ] 낮/밤 버튼으로 같은 존의 day/night가 전환된다.
- [ ] 배경 이미지에 물고기, 텍스트, UI가 없다.
- [ ] 광선/물결/입자 레이어와 배경 효과가 중복되지 않는다.
- [ ] 중앙 유영 공간이 비어 있다.
- [ ] 상단/하단 safe area와 핵심 배경이 충돌하지 않는다.
- [ ] 밤 배경에서도 물고기가 잘 보인다.
- [ ] 모바일 세로형에서 우선 검증했다.
- [ ] 태블릿/PC에서도 비율이 깨지지 않는다.
