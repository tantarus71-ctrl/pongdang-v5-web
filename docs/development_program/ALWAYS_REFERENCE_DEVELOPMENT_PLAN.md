# 퐁당퐁당 곤지암천 개발 프로그램 상시 참조 문서

## 목적
이 디렉토리는 앞으로 기능을 추가하거나 수정할 때 항상 먼저 확인하는 개발 프로그램 기준 문서를 보관한다.

## 상시 참조 우선순위
1. `docs/MASTER_개발기획서_상시참조.txt`
2. `docs/STEP_2026-04-27_MASTER_WORKFLOW_RULES.md`

4. `docs/STEP_2026-04-28_BUBBLE_EFFECT_PROMPT.md`

6. 현재 작업 단계별 문서

## 공통 작업 순서
1. 기준 안정본 확인
2. 이번 단계 목표 1개만 확정
3. 관련 HTML/CSS/JS/config 분석
4. 수정 파일과 fallback 설계
5. 최소 패치 적용
6. 문법/경로/레이어/메뉴 충돌 검증
7. 개발기획서 업데이트
8. 다음 단계 1개만 제안

## 이펙트 작업 고정 규칙
- 배경은 `#bg`에서만 관리한다.
- 자연 조명은 `.godrays`, `.caustics` 중심으로 관리한다.
- 물방울/부유 입자는 `.particles`에서만 관리한다.
- 모든 전역 이펙트는 `pointer-events:none`을 유지한다.
- UI보다 높은 z-index를 쓰지 않는다.
- 물고기 클릭 가능 상태를 방해하지 않는다.
- 모바일 세로형에서 먼저 검증한다.

## 현재 물방울 기준
- 작은 부유 입자와 투명 기포를 섞는다.
- 존마다 다른 `BUBBLE_PROFILES`를 사용한다.
- 기포는 실제 물방울처럼 외곽선, 내부 하이라이트, 부드러운 상승 움직임을 가진다.
- 과한 SF 느낌보다 자연 수중 생태감을 우선한다.

## 현재 2.5D 수족관 기준
- 5개 존 낮/저녁 배경은 독립적으로 유지한다.
- 배경, 조명, caustics, 생태 오브젝트, 입자, 물고기, UI는 레이어 계약을 지킨다.
- 수족관용/카드용/도감용/팝업용 어종 이미지는 별도 자산으로 관리한다.
- 신규 어종은 버들치, 피라미, 쉬리, 각시붕어, 모래무지 순서로 확장한다.
