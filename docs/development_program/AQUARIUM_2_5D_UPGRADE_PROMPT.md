# 퐁당퐁당 곤지암천 2.5D 수족관 단계별 업그레이드 프롬프트

## 현재 구조 체크 결과
- `#bg`는 실제 존별 낮/저녁 배경 전용 레이어이며 z-index 0이다.
- `.far-haze`, `.godrays`, `.caustics`는 배경 위 조명/물결 레이어이며 UI 클릭을 막지 않는다.
- `.eco-layer`는 돌/수초/자갈 장식 레이어이며 z-index 12이다.
- `.particles`는 부유 입자와 물방울 레이어이며 z-index 30, `pointer-events:none`이다.
- `.fish-layer`는 물고기 전용 레이어이며 z-index 38이다.
- zone 메뉴, 하단 카드, 상단 메뉴, 팝업은 모두 그 위에 별도 z-index로 올라간다.
- `applyZoneVisual()`은 존별 낮/저녁 배경, 광선, caustics 강도만 바꾼다.
- `makeParticles()`는 `BUBBLE_PROFILES`를 통해 존별 물방울 위치와 밀도를 다르게 만든다.

## 최종 목표
각 존의 맵 배경은 독립적으로 보이고, 낮/저녁 전환도 정상 작동하며, 광선/물결/수초/물고기/UI 레이어가 서로 덮어 배경을 가리지 않는다. 전체 수족관은 아이들 눈높이에 맞게 선명하고 친근하지만 유치하지 않고, 실제 곤지암천 하천 생태 느낌을 반영한다.

## 절대 작업 규칙
1. 한 단계에서는 기능 1개만 바꾼다.
2. `#bg`에는 배경 이미지만 둔다.
3. 자연 조명은 `.godrays`, `.caustics`, `.far-haze`에서만 다룬다.
4. 돌/수초/이끼/자갈은 `.eco-layer`에서만 다룬다.
5. 물방울/부유입자는 `.particles`에서만 다룬다.
6. 물고기 이미지는 `.fish-layer`와 종별 asset config에서만 다룬다.
7. 전역 이펙트 레이어는 항상 `pointer-events:none`을 유지한다.
8. UI보다 높은 z-index를 새로 만들지 않는다.
9. 모바일 세로형 수족관 구도를 먼저 검증한다.
10. 중앙 물고기 유영 공간을 가리지 않는다.

## 기준 레이어 계약
```text
z 0      #bg 실제 배경
z 1      aquarium frame/highlight
z 2      far-haze 원경 안개
z 5      godrays 햇빛/달빛 광선
z 7      caustics 물결 반사
z 12     eco-layer 돌/수초/자갈/이끼
z 30     particles 부유입자/물방울
z 38     fish-layer 물고기
z 50~68  fish highlight/관찰 링
z 76+    zone UI, bottom card
z 80+    top/bottom main UI
z 118+   panel/popup/card
z 260+   camera/explore/audio panels
z 430+   modal/toast/top overlay
```

## 단계별 진행 프롬프트

### 1단계: 존별 배경/낮저녁 독립 검증
```text
너는 v30A1 수족관의 존별 배경 전환을 검증하는 개발자다.

목표:
웃물/여울/잔여울/깊물/물모이의 낮/저녁 배경이 독립적으로 보이고, 메뉴 클릭과 밤낮 전환 시 다른 존 배경이 섞이지 않게 한다.

확인:
- ZONES의 day/night 경로 10개가 모두 존재하는가?
- HTTP 200 image/png로 응답하는가?
- applyZoneVisual()이 currentZoneId와 isNight 기준으로 정확한 bgSrc를 선택하는가?
- #bg.dataset.zone, #bg.dataset.mode, #bg.dataset.src가 현재 상태와 일치하는가?
- PondangV30A1Debug.debugBackground()의 computedImage가 실제 배경 URL인가?

금지:
- 배경을 CSS 여러 곳에 중복 지정
- index.html에 존별 배경 분기 추가
- UI 또는 물고기 레이어 수정
```

### 2단계: 존별 자연 조명 안정화
```text
목표:
각 존 낮/저녁 분위기에 맞는 광선과 물결 반사를 조정하되 배경을 덮지 않는다.

기준:
- 낮 godrays opacity는 0.34 이하
- 낮 caustics opacity는 0.26 이하
- 밤 godrays는 푸른 달빛 느낌으로 0.14 전후
- 밤 caustics는 0.10 전후
- 광선은 screen/soft-light 계열로 자연스럽게

존별:
- 웃물: 깨끗하고 편안한 햇빛, 가장 밝고 투명
- 여울: 반짝임과 굴절이 가장 활발
- 잔여울: 부드러운 확산광, 오래 봐도 피곤하지 않게
- 깊물: 굵고 차분한 푸른 광선, 무섭지 않게
- 물모이: 생명감 있는 은은한 입체광

검증:
UI, 팝업, 물고기 클릭 영역이 조명 레이어에 가려지면 실패.
```

### 3단계: 2.5D 생태 오브젝트 레이어 분리
```text
목표:
수초, 자갈, 바위, 이끼, 유기물 요소를 전경/중경/후경 느낌으로 나누되 중앙 유영 공간을 확보한다.

구조:
- 후경: 배경 이미지에 포함된 먼 수초/바위 느낌
- 중경: eco-layer의 작은 수초/자갈
- 전경: 화면 하단/좌우 가장자리의 큰 수초/바위

존별:
- 웃물: 밝은 자갈, 얇은 수초, 적은 바위
- 여울: 중간 자갈과 바위 강조, 물살에 휘는 수초
- 잔여울: 수초 군락과 부드러운 입자감
- 깊물: 큰 바위와 그림자, 원근감 강하게
- 물모이: 다양한 수초/자갈/작은 유기물, 산만하지 않게

금지:
- 중앙 36~62% 유영 영역을 과도하게 가리기
- 하단 UI safe area 안으로 오브젝트를 깊게 침범시키기
```

### 4단계: 물방울/부유입자 고도화
```text
목표:
BUBBLE_PROFILES를 기준으로 각 존마다 물방울 위치, 크기, 속도, 밀도를 다르게 한다.

기준:
- 작은 부유 입자와 투명 기포를 섞는다.
- 기포는 외곽선, 내부 하이라이트, 천천히 올라가는 움직임을 가진다.
- particles z-index 30, pointer-events:none 유지.

존별:
- 웃물: 적고 맑은 기포
- 여울: 중앙 물살을 따라 빠른 기포
- 잔여울: 수초 주변의 부드러운 기포
- 깊물: 드문드문 느린 기포
- 물모이: 다양한 크기의 풍성한 기포
```

### 5단계: 어종 자산 구조 확장
```text
목표:
버들치 이후 피라미, 쉬리, 각시붕어, 모래무지를 추가할 수 있게 수족관용/카드용/도감용/팝업용 자산을 분리한다.

필수 폴더 구조:
assets/fish/{speciesId}/aquarium/
assets/fish/{speciesId}/card/
assets/fish/{speciesId}/dex/
assets/fish/{speciesId}/popup/

수족관용:
- 가볍고 투명한 PNG
- 방향 전환용 측면/사선 프레임 우선
- 모바일에서 작게 보여도 종 특징이 보임

카드용:
- 수집 카드 느낌
- 아이들이 얻었다는 성취감
- 배경 포함 가능하되 카드 내부에서만 사용

도감용:
- 실제 생태 특징이 잘 보임
- 지느러미/꼬리/몸색이 명확함

팝업용:
- 설명용 대표 이미지
- 아이가 눌렀을 때 바로 알아볼 수 있는 큰 이미지

금지:
- 수족관용 이미지를 카드/도감/팝업에 무조건 재사용
- 이미지 배경이 불투명해서 맵 배경을 가림
```

## 어종별 이미지 제작 프롬프트 템플릿

```text
퐁당퐁당 곤지암천 어린이 생태학습용 민물고기 이미지 자산을 제작한다.

어종명:
{speciesName}

실제 생태 특징:
{habitat, bodyShape, behavior}

아이들이 알아보기 쉬운 특징:
{kidFriendlyFeature}

공통 스타일:
- 반실사 카툰 스타일
- 선명하고 친근하지만 유치하지 않게
- 실제 토종 민물고기 느낌 유지
- 과한 캐릭터화 금지
- 모바일 세로형 수족관에서 작게 보여도 식별 가능
- 색감은 실제 생태 특징을 따르되 어린이가 보기 좋게 정리

수족관용:
- 투명 배경 PNG
- 가벼운 용량
- 측면/사선 방향 프레임
- 물속에서 움직일 때 자연스럽게 보이는 형태

카드용:
- 수집 카드에 들어갈 대표 이미지
- 조금 더 선명하고 보상감 있게
- 종 특징이 잘 보이게

도감용:
- 형태와 색상, 지느러미, 꼬리 특징이 명확
- 설명 학습용으로 정확성 우선

팝업용:
- 아이가 클릭했을 때 크게 볼 대표 이미지
- 친근하고 부드러운 표정

투명 배경:
- 수족관용은 반드시 투명 PNG
- 카드/도감/팝업용은 앱 디자인에 맞춰 분리 가능

색상:
{speciesColor}

지느러미/꼬리 특징:
{finTailFeature}
```

## 우선 어종별 요약 프롬프트

### 버들치
- 맑은 상류/여울의 중층~상층.
- 길고 가는 몸, 올리브 갈색 등, 은백색 배, 흐린 가로 줄무늬.
- 빠르지만 조심스럽게 무리 지어 유영.

### 피라미
- 얕은 물과 여울 주변.
- 작고 날렵하며 햇빛에 반짝이는 은빛 몸.
- 무리로 빠르게 움직여 활기 있는 느낌.

### 쉬리
- 깨끗한 자갈 바닥과 물살 있는 곳.
- 길고 날렵한 몸, 줄무늬/몸선이 분명.
- 자갈 근처를 빠르게 지나가는 느낌.

### 각시붕어
- 수초 많은 잔잔한 물가.
- 작고 둥근 편, 은은한 색감과 예쁜 몸빛.
- 수초 사이에서 부드럽고 조심스럽게 이동.

### 모래무지
- 모래와 자갈이 섞인 바닥 가까이.
- 바닥 생활형 몸, 아래쪽 먹이 탐색 느낌.
- 깊물/물모이의 바닥권에서 차분하게 움직임.

## 최종 검증
- 5개 존 낮/저녁 배경 독립 표시
- 배경 위 조명/caustics/수초/입자/물고기/UI 충돌 없음
- 중앙 물고기 유영 공간 확보
- UI safe area 보호
- 낮/밤 모두 어린이가 보기 편함
- 모바일 세로형 우선, 태블릿/PC 비율 유지
- 신규 어종 자산은 용도별로 분리됨
