# 퐁당퐁당 V5 v4.5.5 이후 통합 개발 기준서

## 1. 현재 기준

- 기준 버전: v4.5.5 최적화·안정화·퀄리티 패스
- 개발 방향: 어종 확장은 잠시 보류하고, 어린이 학습 경험·현장 탐험 구조·카메라/VR/GPS 설계를 먼저 고정한다.
- 운영 기준: 웹 테스트본과 앱 기준본을 동시에 유지한다.
- 표기 기준: 개발/카피라이터 표기는 JOHN CHOI를 유지한다.

## 2. 핵심 목표

퐁당퐁당은 곤지암천 수중 생태계를 어린이 눈높이로 체험하는 디지털 생태학습 플랫폼이다. 현재 수족관 화면 중심 구조를 유지하면서, 향후 실제 곤지암천 현장 탐험으로 확장한다.

최종 목표는 아이들이 화면 속 물고기를 따라가다 실제 곤지암천의 물, 돌, 풀, 꽃, 곤충, 새, 별빛까지 자연스럽게 바라보게 만드는 것이다.

## 3. 어린이 눈높이 설계 원칙

- 설명은 짧게 한다.
- 버튼은 크고 의미가 분명해야 한다.
- 메뉴는 수족관보다 작아야 한다.
- 실패감을 주지 않는다.
- 발견하면 즉시 칭찬한다.
- 자연을 만지기보다 관찰하도록 안내한다.
- 위험한 장소로 이동을 유도하지 않는다.
- 아이가 화면을 오래 보더라도 피로하지 않게 움직임을 부드럽게 유지한다.

예시 문구:

- 잘 찾았어요. 작은 생물도 소중해요.
- 오늘 못 봐도 괜찮아요. 자연은 천천히 보여줘요.
- 만지지 말고 눈으로만 살펴봐요.

## 4. 곤지암천 5존 기준

| 존 | 학습 방향 |
|---|---|
| 웃물 | 맑은 물, 작은 물고기, 상류형 생태 |
| 여울 | 물살, 자갈, 빠른 움직임 |
| 잔여울 | 얕은 흐름, 관찰하기 쉬운 생물 |
| 깊물 | 깊은 곳, 숨어 사는 생물 |
| 물모이 | 물길이 만나는 곳, 다양한 생태 변화 |

## 5. 현재 UI 기준

- 수족관이 메인이다.
- 상단 문구는 작고 명확하게 유지한다.
- 메뉴는 아이콘/이모지 기반으로 직관화한다.
- 음성 버튼은 보조 기능이며, 수족관 시야를 방해하지 않아야 한다.
- 팝업은 짧은 설명, 음성 듣기, 알겠어요 구조로 유지한다.
- 도감·미션·카메라·결과 보기 기능은 하단 메뉴와 충돌하지 않게 관리한다.

## 6. 카메라 탐험 기능

카메라 탐험은 아이가 실제 곤지암천 주변에서 눈앞의 자연을 관찰하고, 앱 안의 생태 정보와 연결하는 기능이다.

초기 방향:

- 사람 얼굴 인식/저장 기능은 넣지 않는다.
- 개인정보·초상권 위험을 피한다.
- 사진 수집보다 관찰 보조에 집중한다.
- 권한 거부 시 fallback 안내를 제공한다.

예시 문구:

- 주변을 천천히 둘러봐요. 물가에 어떤 식물이 보이나요?
- 돌 아래에는 작은 생물이 숨어 있을 수 있어요.
- 사진을 찍지 않아도 괜찮아요. 먼저 눈으로 관찰해 봐요.

## 7. GPS 기반 현장 탐험 기능

GPS 기능은 아이가 곤지암천의 어느 구간에 있는지에 따라 학습 화면을 다르게 보여주는 기능이다.

초기 방향:

- 좌표를 복잡하게 보여주지 않는다.
- 정밀 추적보다 구간 기반 전환을 우선한다.
- 위험 구역 접근 유도는 금지한다.
- 경쟁형 위치 미션은 초기 단계에서 제외한다.
- 위치 권한 거부 시 수동 구간 선택으로 대체한다.

예시 문구:

- 여기는 물살이 조금 빠른 곳이에요.
- 이 구간에서는 피라미처럼 빠르게 움직이는 물고기를 만날 수 있어요.
- 깊은 곳은 가까이 가지 말고, 멀리서 관찰해요.

## 8. VR·시네마 관찰 모드

VR 기능은 초기에는 고가의 VR 기기 연동이 아니라, 모바일 화면 안에서 물속에 들어간 듯한 몰입감을 주는 시네마 관찰 모드로 설계한다.

기준:

| 요소 | 적용 기준 |
|---|---|
| 화면 | 수족관을 최대한 크게 |
| 메뉴 | 작고 단순하게 |
| 움직임 | 느리고 부드럽게 |
| 음성 | 짧은 설명 중심 |
| 색감 | 밝지만 과하지 않게 |
| 안전성 | 어지럽지 않은 움직임 |

VR/시네마 모드는 아이들이 게임을 한다는 느낌보다 물속을 조용히 들여다본다는 느낌을 주는 것이 중요하다.

## 9. 향후 확장 로드맵

순서는 수중 생태계를 먼저 안정화한 뒤, 주변 자연으로 확장한다.

1. 수중 생태계: 물고기, 수초, 바위, 물살
2. 물가 식물과 꽃: 계절별 관찰 카드
3. 곤충과 작은 동물: 잠자리, 개구리, 물가 생물
4. 새와 주변 동물: 하천 주변에서 볼 수 있는 생명
5. 계절 변화: 봄·여름·가을·겨울 장면
6. 지역 별자리: 밤물 모드와 연결되는 하늘 관찰

## 11. 안정성 원칙

- 같은 기능은 중복 구현하지 않는다.
- 새 코드 추가 전 기존 기능과 충돌 여부를 확인한다.
- 장식/배경/오브젝트 레이어는 pointer-events:none을 유지한다.
- 물고기 클릭 hitbox는 이미지 효과와 분리한다.
- 카메라/GPS/음성 기능은 권한 거부 fallback을 반드시 둔다.
- index.html과 app_assets/index.html은 항상 함께 갱신한다.
- 변경 후 JS 문법 검사와 웹/앱 동일성 검사를 수행한다.
