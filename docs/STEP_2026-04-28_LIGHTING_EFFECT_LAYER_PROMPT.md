# 2026-04-28 조명/SF 이펙트 레이어 작업 프롬프트

## 현재 레이어 점검
- `#bg`: z-index 0, 실제 존별 낮/저녁 맵 배경.
- `.aquarium::before`: z-index 1, 수족관 프레임/내부 하이라이트.
- `.far-haze`: z-index 2, 원경 수중 안개.
- `.godrays`: z-index 5, 햇빛/달빛 광선.
- `.caustics`: z-index 7, 바닥 물결 반사.
- `.eco-layer`: z-index 12, 돌/수초/자갈 등 생태 장식.
- `.particles`: z-index 30, 부유 입자.
- `.fish-layer`: z-index 38, 물고기.
- `.debug-chip`, `.zone-strip`, `.bottom-card`: z-index 75~76, 정보 UI.
- `.topbar`, `.bottom-nav`: z-index 80~86, 주요 메뉴.
- 팝업/패널: z-index 118 이상.
- 오디오/사진/GPS 팝업: z-index 260~500.

## 핵심 원칙
- 조명은 배경 위에 보이되 UI와 물고기 클릭을 방해하지 않는다.
- 모든 조명/SF 이펙트 레이어는 `pointer-events:none`이어야 한다.
- 배경이 안 보일 정도의 불투명 오버레이는 금지한다.
- 낮/저녁 모드는 같은 이펙트 구조를 쓰되 opacity, blend mode, 색온도만 다르게 한다.
- 새 이펙트는 반드시 전용 컨테이너에 넣고 기존 UI/물고기 DOM에는 직접 섞지 않는다.

## 권장 z-index 계약
- `z 0`: 실제 배경 이미지.
- `z 1~4`: 배경 보정, 원경 안개, 수심 그라데이션.
- `z 5~9`: 자연 조명, 햇빛/달빛 광선, 바닥 caustics.
- `z 10~18`: 돌/수초/이끼 등 배경성 생태 요소.
- `z 20~34`: 부유 입자, 약한 수중 미세 이펙트.
- `z 35~48`: 물고기와 물고기 주변 하이라이트.
- `z 50~68`: 클릭 가능한 물고기 강조/관찰 링. 단, UI 영역 침범 금지.
- `z 70~99`: 고정 UI.
- `z 100+`: 패널/팝업/카드/사진/GPS/오디오.
- `z 240+`: 전체 화면 패널.
- `z 430+`: 최상위 모달/토스트.

## 자연 조명 프롬프트
```text
너는 퐁당퐁당 곤지암천 v30A1의 수중 조명 레이어를 안정화하는 개발자다.

목표:
존별 배경 이미지 위에 자연스러운 햇빛/달빛/물결 반사를 적용하되, 배경 이미지가 가려지거나 물고기/메뉴/팝업 클릭과 충돌하지 않게 한다.

작업 순서:
1. 현재 DOM 레이어 확인: #bg, .far-haze, .godrays, .caustics, .eco-layer, .particles, .fish-layer, UI.
2. z-index 계약 확인: 배경 0, 안개 2, 광선 5, caustics 7, 생태 12, 입자 30, 물고기 38, UI 76 이상.
3. 조명 레이어는 pointer-events:none을 유지한다.
4. 낮 모드: 햇빛 광선은 밝지만 opacity 0.34 이하, caustics 0.26 이하로 제한한다.
5. 저녁/밤 모드: 푸른 림라이트와 약한 달빛만 사용하고, 배경을 검게 덮지 않는다.
6. mix-blend-mode는 screen/soft-light 중심으로 사용하되, 화면이 하얗게 뜨거나 검게 죽으면 즉시 opacity를 낮춘다.
7. 애니메이션은 transform/opacity만 사용하고 filter/box-shadow를 과하게 반복 애니메이션하지 않는다.
8. 모바일에서 60fps를 방해하지 않도록 레이어 수와 blur를 제한한다.
9. 메뉴, 하단 카드, 팝업, 물고기 클릭 영역과 겹치거나 클릭을 막으면 실패로 본다.
10. 적용 후 각 존 낮/저녁 10개 상태를 전부 확인한다.

검증:
- 배경이 실제 이미지로 보이는가?
- 광선이 배경 위에 자연스럽게 얹히는가?
- 물고기보다 너무 앞에 나와 관찰을 방해하지 않는가?
- UI 버튼 클릭이 정상인가?
- 팝업/카드/사진/GPS/오디오 패널이 조명 레이어 위에 보이는가?
- 모바일 세로형에서 과도한 깜빡임/버벅임이 없는가?

절대 금지:
- 조명 레이어에 pointer-events:auto 사용
- UI보다 높은 z-index 사용
- 배경을 덮는 단색/고불투명 오버레이
- 물고기 클릭 링보다 강한 SF 플래시
- 여러 기능을 한 번에 수정
- index.html에 이펙트 로직을 몰아넣기
```

## SF 이펙트 추가 프롬프트
```text
너는 퐁당퐁당 곤지암천 v30A1의 어린이 생태학습용 SF 이펙트 레이어를 추가하는 개발자다.

목표:
생태 수족관 느낌을 해치지 않는 범위에서 관찰 성공, 카드 획득, 미션 완료 같은 순간에 짧고 부드러운 SF 이펙트를 보여준다.

구조:
- 새 이펙트는 `.effect-layer` 또는 `.fish-highlight-layer` 전용 컨테이너에만 추가한다.
- `.effect-layer`는 물고기보다 앞, UI보다 뒤에 둔다.
- 모든 이펙트는 pointer-events:none으로 둔다.
- 관찰 성공 이펙트는 activeFront 물고기 주변에만 표시한다.
- 미션/카드 획득처럼 UI가 중요한 순간은 기존 모달 z-index를 넘지 않는다.

권장 위치:
- 배경 분위기 SF: z-index 8~11
- 부유 입자형 SF: z-index 28~34
- 물고기 관찰 하이라이트: z-index 50~68
- UI 축하 이펙트는 패널 내부에서만 처리하고 전역 레이어를 덮지 않는다.

품질 기준:
- 어린이용 앱이므로 과한 번쩍임, 빠른 점멸, 눈부심 금지.
- 자연 생태 분위기를 우선하고 SF는 보조 장식으로 제한.
- 애니메이션은 600~1800ms 안에서 끝낸다.
- 동시에 3개 이상 대형 이펙트가 뜨지 않게 한다.
- prefers-reduced-motion 환경에서는 축소하거나 정지한다.

검증:
- 메뉴 클릭 정상
- 물고기 클릭 정상
- 팝업/카드/도감/미션/카메라/GPS/오디오 패널 정상
- 낮/저녁 배경 모두에서 보이지만 과하지 않음
- 프레임 저하 없음
```
