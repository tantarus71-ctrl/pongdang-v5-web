## 1. 기본 원칙

퐁당퐁당의 물고기 디자인은 단순 이미지 추가가 아니다. 어종 1종을 추가할 때마다 다음 요소를 하나의 시스템 단위로 등록해야 한다.

- 대표 이미지
- 도감 카드 이미지
- 팝업 이미지
- 수조 표시 이미지
- 서식 구역
- 수심층
- 이동 성향
- 3D처럼 보이는 행동권
- 도감 설명
- 팝업 설명
- 미션/퀴즈/반짝 연동 여부

## 2. 이미지 제작 공통 기준

모든 어종 이미지는 다음 기준을 따른다.

- 어종당 1마리 기준
- 완전 측면 구도
- 배경 투명 PNG
- 텍스트 없음
- 라벨 없음
- 워터마크 없음
- 그림자 없음 또는 수조용에서만 최소 적용
- 모바일 웹앱/AR 오버레이에 사용 가능한 고해상도 자산
- 카드용과 팝업용은 같은 개체/같은 스타일 계열 유지
- 수조용 이미지는 별도 최적화 가능
- 어린이 학습용이므로 과도하게 복잡하지 않게 제작
- 실제 종 특징은 유지하되, 친근한 반입체 느낌을 허용

## 3. 스타일 분리 기준

### 3-1. 수조용 이미지

수조용 이미지는 실제 물속에서 헤엄치는 느낌을 우선한다.

- 준실사 또는 반입체 스타일
- 머리 방향 명확
- 꼬리 방향 명확
- 확대/축소 시 실루엣 유지
- z-depth 이동에 어색하지 않은 몸 비율
- 원근 스케일 변화에 견딜 수 있는 형태
- 너무 납작한 카드형 이미지는 피함

### 3-2. 도감 카드용 이미지

도감 카드용 이미지는 어린이가 수집하고 싶어 하는 카드성을 우선한다.

- 밝고 선명한 실루엣
- 종 특징이 한눈에 보이게 제작
- 복잡한 배경 없음
- 카드 영역 안에서 안정적으로 보이는 비율
- 학습 정보와 함께 읽히는 친근한 느낌

### 3-3. 팝업용 이미지

팝업용 이미지는 카드보다 크게 보이며 설명과 함께 쓰인다.

- 카드용과 같은 개체 또는 같은 스타일 계열
- 종 특징을 더 분명하게 표현
- 지나친 실사보다 어린이가 무섭지 않게 조정
- 설명 텍스트와 충돌하지 않는 비율

## 5. 3D처럼 보이는 유영 기준

현재 개발 방향은 물고기가 단순히 2D로 좌우 이동하는 방식이 아니다. 물고기가 수조 안쪽을 크게 돌고, 앞뒤 깊이를 오가며, 화면 가까이 왔다가 멀어지는 반입체 유영을 기준으로 한다.

따라서 각 어종은 다음 값을 가져야 한다.

- z-depth
- 앞뒤 이동 범위
- 원근 스케일 변화
- 회전 반경
- 속도
- 수심층
- 단독/군영 성향
- 회전 방식

## 6. 5방향 반입체 PNG 확장 기준

고급 연출이 필요한 어종은 5방향 PNG를 사용할 수 있다.

권장 방향:

1. 좌측 측면
2. 좌측 3/4
3. 정측면
4. 우측 3/4
5. 우측 측면

추가 프레임:

- 꼬리 흔들림 2~3프레임
- 지느러미 미세 움직임 1~2프레임

적용 방식:

- 이동 방향에 따라 이미지 교체
- z-depth에 따라 스케일 조정
- 회전 구간에서 이미지 전환
- 빠른 회전보다 느린 방향 전환 우선

## 7. 어종 적용 순서

5. 서리비늘

5. 모바일 화면 확인
6. 이상 없을 때 다음 어종으로 이동

## 8. 버들치 기준 시안

버들치는 기준 어종으로 사용한다.

### 8-1. 버들치 시각 특징

- 토종 버들치에 최대한 가깝게
- 몸통은 자연스럽고 너무 두껍지 않게
- 가운데 검은 줄은 강하게 넣지 않음
- 가운데 검은 줄은 60~80% 정도 흐리게 표현
- 전체 색감은 자연스러운 민물고기 톤
- 약간 노란빛 허용
- 꼬리지느러미에 약간 붉은 기운 허용
- 머리 방향 명확
- 꼬리 방향 명확
- 배경 100% 투명
- 그림자 제거
- 입체감은 살리되 과하지 않게
- 어린이용 카드에서는 친근한 카툰형 특징 보강 가능

### 8-2. 버들치 스타일 판정

버들치는 다음 기준으로 제작한다.

`실제 버들치 특징을 최대한 살린 반입체·친화형 기준 어종`

## 9. 데이터 구조 기준

어종 관리는 2안 단일 데이터 테이블 구조를 기준으로 한다.

권장 명칭:

`fish_database_option2`

관리 방식:

- 어종별 정보를 흩어두지 않는다.
- 이미지, 설명, 행동권, 존, 미션 정보를 하나의 객체로 관리한다.
- 삭제/수정/추가는 데이터 객체 단위로 처리한다.
- 함수 안에 어종 정보를 직접 박아 넣지 않는다.

## 10. 카드·팝업·수조 관계

| 구분 | 목적 | 기준 |
|---|---|---|
| 카드 이미지 | 수집/도감 | 선명하고 귀엽게, 특징 강조 |
| 팝업 이미지 | 상세 설명 | 카드보다 크게, 설명과 조화 |
| 수조 이미지 | 유영 연출 | 원근감/회전/스케일 변화 최적화 |

## 11. 22종 확장 기준

곤지암천 실제 생태계와 어린이 학습성을 기준으로 22종까지 확장할 수 있다.

확장 시 반드시 확인할 것:

- 실제 곤지암천/경안천권 출현 가능성
- 어린이 학습 가치
- 도감 설명 난이도
- 이미지 제작 난이도
- 수조 내 크기 균형
- 희귀/일반 구분
- 실제종/상상종 구분
