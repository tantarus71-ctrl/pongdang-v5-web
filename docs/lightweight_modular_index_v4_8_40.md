# 퐁당퐁당 v4.8.40 index.html 경량화·분산구조 전환 기록

작성 기준: 2026-04-26
저장소: tantarus71-ctrl/pongdang-v5-web
목표: 단일 거대 index.html을 경량화 가능한 분산 구조로 전환하기 위한 안전 실행본 생성

## 1. 목적

기존 app_assets/index.html은 HTML, CSS, JavaScript, 데이터가 한 파일에 집중된 단일 구조다.

문제점:

- 파일이 커서 부분 수정이 어렵다.
- GitHub 도구에서 전체 본문이 잘릴 수 있다.
- 작은 수정도 전체 기능 손상 위험이 있다.
- CSS/JS 중복 추적이 어렵다.
- 핸드폰/태블릿/PC 최적화 패치를 안정적으로 누적하기 어렵다.

v4.8.40에서는 원본을 직접 덮어쓰지 않고, 경량화된 신규 실행본을 별도로 만들었다.

## 2. 신규 구조

```txt
app_assets/index_v4_8_40.html
app_assets/v4_8_40/css/pongdang-ui.css
app_assets/v4_8_40/js/pongdang-data.js
app_assets/v4_8_40/js/pongdang-app.js
```

## 3. 파일 역할

### 3-1. index_v4_8_40.html

역할:

- 최소 HTML 구조만 담당
- 수족관 영역
- 상단 안내 영역
- 구간/낮밤 컨트롤 영역
- 하단 메뉴 영역
- 도감/반짝/카메라 시트 영역
- 물고기 상세 모달 영역

HTML 안에는 긴 CSS와 긴 JS를 넣지 않는다.

### 3-2. pongdang-ui.css

역할:

- 핸드폰/태블릿/PC 반응형 UI
- 수족관 크기 최적화
- 하단 메뉴 이모지 배치
- 시트/모달 스타일
- 작은 휴대폰 겹침 방지
- PC 중앙 전시형 배치

### 3-3. pongdang-data.js

역할:

- ZONES 데이터
- MENU 데이터
- FISH 데이터
- 어종 설명/이미지 경로

향후 피라미, 쉬리, 각시붕어 추가는 이 파일을 중심으로 한다.

### 3-4. pongdang-app.js

역할:

- 구간 버튼 렌더링
- 낮/밤 버튼 렌더링
- 하단 메뉴 렌더링
- 도감 카드 렌더링
- 물고기 팝업
- 간단한 물고기 유영 애니메이션
- 시트/모달 닫기
- 키보드 ESC 닫기

## 6. 안정성 기준

v4.8.40은 원본 index.html을 변경하지 않는다.

따라서 실패해도 원본은 즉시 유지된다.

다음 사항을 반드시 확인한다.

- HTML이 정상 로드되는가
- CSS 경로가 정상인가
- JS module 경로가 정상인가
- 버들치 이미지가 보이는가
- 도감 카드가 열리는가
- 물고기 모달이 열리는가
- 하단 메뉴 4개가 겹치지 않는가
- 작은 휴대폰에서 보조문구가 숨겨지는가
- 태블릿/PC에서 중앙 정렬이 유지되는가

## 7. 원본 index.html 교체 조건

아래 조건을 모두 만족한 뒤에만 원본 index.html 교체를 고려한다.

1. index_v4_8_40.html이 핸드폰에서 정상 작동
2. PC에서 정상 작동
3. 태블릿 비율에서 정상 작동
4. 기존 주요 기능 중 반드시 유지할 항목 목록 확정
5. 누락 기능 이식 완료
6. 새 구조에서 오류 로그 없음
7. 원본 index.html 백업 파일 생성
8. 최종 교체 커밋 생성
