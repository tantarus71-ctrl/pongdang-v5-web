# 2026-04-28 존별 물방울 이펙트 작업 프롬프트

## 목표
퐁당퐁당 곤지암천 v30A1의 물방울/부유 입자 이펙트를 실제 수중 기포처럼 보이게 개선한다. 기포는 조금 더 크게 보이되, 배경/물고기/UI를 가리지 않고 각 존마다 다른 위치와 밀도로 올라오게 한다.

## 현재 기준
- 이펙트 레이어: `.particles`
- 레이어 위치: z-index 30
- 클릭 충돌 방지: `pointer-events:none`
- 물고기 레이어: z-index 38
- UI 레이어: z-index 76 이상

## 구현 원칙
- 물방울은 단순 흰 점이 아니라 투명한 원형 기포처럼 보여야 한다.
- 크기는 기존보다 조금 키우되 과도하게 커서 수족관을 덮으면 안 된다.
- 작은 부유 입자와 실제 물방울을 섞는다.
- 각 존마다 기포가 올라오는 위치가 달라야 한다.
- 기포는 아래에서 위로 올라가며 약간 좌우로 흐른다.
- 빠른 점멸, 과한 반짝임, SF 같은 강한 플래시는 금지한다.
- `transform`과 `opacity` 중심으로 애니메이션하고, 무거운 filter 반복은 피한다.
- 전체 레이어는 반드시 `pointer-events:none`을 유지한다.

## 존별 기포 방향
- 웃물: 좌우 가장자리의 풀/돌 근처에서 적은 양의 맑은 기포.
- 여울: 중앙 물살을 따라 조금 더 빠르고 다양한 기포.
- 잔여울: 좌우 수초 주변에서 부드럽고 작은 기포.
- 깊물: 가장자리와 깊은 바닥 근처에서 드문드문 느린 기포.
- 물모이: 여러 위치에서 생명감 있게 다양한 크기의 기포.

## 필수 구조
```text
BUBBLE_PROFILES = {
  zoneId: {
    count,
    size,
    large,
    opacity,
    x,
    top,
    drift,
    dur
  }
}
```

## 검증 체크리스트
- 5개 존에서 기포 위치가 서로 다른가?
- 낮/저녁 모두에서 보이지만 배경을 가리지 않는가?
- 메뉴, 팝업, 도감, 미션, 카메라, GPS, 오디오 버튼 클릭을 막지 않는가?
- 물고기 관찰 클릭 영역과 충돌하지 않는가?
- 모바일에서 버벅임이 없는가?
- 기포가 실제 물속에서 올라오는 느낌인가?

## 금지
- `.particles`에 `pointer-events:auto` 사용 금지
- UI보다 높은 z-index 사용 금지
- 단색 큰 원을 많이 띄워 화면을 가리는 것 금지
- 물고기보다 더 시선을 빼앗는 과한 이펙트 금지
- 모든 존에서 같은 위치와 같은 속도 사용 금지
