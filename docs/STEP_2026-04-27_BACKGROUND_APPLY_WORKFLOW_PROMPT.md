# 단계별 개발계획서: 순차 배경 적용 작업 프롬프트

작성일: 2026-04-27

## 1. 기준 안정본 확인

- 기준 버전: v30A-1 audio stability final
- 기준 경로: `app_assets/pongdang_gonjiam_v30A1_audio_stability_final/`
- 기존 배경 구조:
  - `.bg`: 실제 배경 이미지
  - `.godrays`: 광선 레이어
  - `.caustics`: 물결 반사 레이어
  - `.eco-layer`: 돌/수초/생태 오브젝트
  - `.particles`: 부유 입자
  - `.fish-layer`: 물고기
  - UI 메뉴와 패널은 배경보다 높은 z-index에서 동작
- 현재 메뉴 구조:
  - `modeBtn`: 낮/밤 전환
  - 하단 메뉴: 탐사, 도감, 미션, 카메라
  - 각 메뉴는 열릴 때 다른 패널을 닫는 구조

## 2. 이번 단계 목표

## 4. 사용자가 올릴 배경 순서와 대상 경로

사용자가 아래 순서로 배경 이미지를 올리면, 반드시 같은 순서로 하나씩 적용한다.

```text
1. 웃물 낮    -> assets/bg/upper/day.png
2. 웃물 저녁  -> assets/bg/upper/night.png
3. 여울 낮    -> assets/bg/rapid/day.png
4. 여울 저녁  -> assets/bg/rapid/night.png
5. 잔여울 낮  -> assets/bg/soft-rapid/day.png
6. 잔여울 저녁 -> assets/bg/soft-rapid/night.png
7. 깊물 낮    -> assets/bg/deep/day.png
8. 깊물 저녁  -> assets/bg/deep/night.png
9. 물모이 낮  -> assets/bg/pool/day.png
10. 물모이 저녁 -> assets/bg/pool/night.png
```

주의:

- 사용자가 “저녁”이라고 말하면 현재 앱의 `night` 배경 슬롯에 적용한다.
- 파일명은 앱 로직과 연결되어 있으므로 임의로 바꾸지 않는다.
- 원본 백업이 필요하면 같은 폴더에 덮어쓰지 말고 별도 백업 폴더에 보관한다.
- 한 번에 여러 장을 적용하지 않는다. 반드시 1장 적용 후 검증한다.

## 5. 순차 적용 작업 프롬프트

아래 프롬프트를 배경 이미지가 올라올 때마다 사용한다.

```text
너는 “퐁당퐁당 곤지암천 v30A-1”의 배경 적용 담당 개발자다.

이번 작업 목표는 사용자가 방금 올린 배경 이미지 1장을 정확한 존/시간대 경로에 적용하고, 배경 교체 후에도 모든 메뉴와 기존 기능이 정상 작동하는지 확인하는 것이다.

반드시 한 번에 배경 1장만 적용한다.

작업 순서:

1. 기준 안정본 확인
- 기준 경로 `app_assets/pongdang_gonjiam_v30A1_audio_stability_final/`가 존재하는지 확인한다.
- `index.html`, `src/app.js`, `src/styles/main.css`, `assets/bg/` 구조를 확인한다.
- 현재 `modeBtn` 낮/밤 전환 구조와 하단 메뉴 구조를 확인한다.

2. 업로드 이미지 식별
- 사용자가 지칭한 이름을 확인한다.
- 가능한 이름은 다음 10개 중 하나여야 한다:
  웃물 낮, 웃물 저녁, 여울 낮, 여울 저녁, 잔여울 낮, 잔여울 저녁, 깊물 낮, 깊물 저녁, 물모이 낮, 물모이 저녁
- 지칭이 모호하면 적용하지 말고 사용자에게 정확한 존/시간대를 다시 확인한다.

3. 대상 경로 매핑
- 웃물 낮 -> assets/bg/upper/day.png
- 웃물 저녁 -> assets/bg/upper/night.png
- 여울 낮 -> assets/bg/rapid/day.png
- 여울 저녁 -> assets/bg/rapid/night.png
- 잔여울 낮 -> assets/bg/soft-rapid/day.png
- 잔여울 저녁 -> assets/bg/soft-rapid/night.png
- 깊물 낮 -> assets/bg/deep/day.png
- 깊물 저녁 -> assets/bg/deep/night.png
- 물모이 낮 -> assets/bg/pool/day.png
- 물모이 저녁 -> assets/bg/pool/night.png

4. 적용 전 백업
- 기존 대상 파일이 있으면 백업 폴더에 복사한다.
- 백업 경로 예:
  assets/bg/_backup/YYYYMMDD_HHMMSS/{zone}_{day-or-night}.png
- 백업 실패 시 덮어쓰지 않는다.

5. 이미지 적용
- 업로드 이미지를 대상 경로에 복사한다.
- 확장자가 png가 아니면 PNG로 변환하거나, 변환이 불가능하면 적용하지 않는다.
- 이미지 방향은 모바일 세로형이어야 한다.
- 이미지 안에 물고기, 텍스트, 로고, UI 버튼이 있으면 적용 전 사용자에게 보고한다.

6. 캐시 무효화
- 적용 후 실행 URL에 새 `cache=Date.now()` 값을 사용한다.
- `PondangV30A1Debug.clearRuntimeCache()`가 가능하면 캐시를 정리하고 다시 연다.
- 캐시 때문에 이전 배경이 보이면 적용 성공이라고 말하지 않는다.

7. 기능 보존 검증
- 배경이 적용된 존으로 이동한다.
- 낮 배경이면 낮 모드에서 확인한다.
- 저녁 배경이면 `modeBtn`으로 밤/저녁 모드로 전환해 확인한다.
- 하단 메뉴 4개를 각각 열고 닫는다:
  탐사, 도감, 미션, 카메라
- 상단 버튼을 확인한다:
  음성, 낮/밤 전환, 전체화면
- 팝업/패널이 동시에 겹쳐 보이지 않는지 확인한다.
- 물고기 유영과 클릭 가능 상태가 유지되는지 확인한다.
- `PondangV30A1Debug.audit()`를 실행해 problems가 있는지 확인한다.

8. 레이어 충돌 검증
- 배경 위 광선 레이어가 과하지 않은지 확인한다.
- 배경의 물결 표현과 `.caustics`가 중복되어 지저분하지 않은지 확인한다.
- 배경 속 수초/돌과 `.eco-layer` 오브젝트가 겹쳐 중앙 유영 공간을 막지 않는지 확인한다.
- 상단 topbar, zone-strip, hint와 배경 핵심 요소가 충돌하지 않는지 확인한다.
- 하단 bottom-card, bottom-nav와 배경 핵심 요소가 충돌하지 않는지 확인한다.

9. 실패 시 처리
- 오류 위치를 보고한다.
- 영향 범위를 확인한다.
- 백업 파일로 회귀 가능한지 판단한다.
- 원인을 분석한다.
- 최소 수정한다.
- 재검증한다.
- MASTER 개발기획서에 오류와 해결 기록을 남긴다.

10. 완료 보고
- 적용한 이미지 이름
- 적용 경로
- 백업 경로
- 메뉴 검증 결과
- 낮/밤 전환 검증 결과
- 레이어 충돌 여부
- 남은 리스크
- 다음에 받을 배경 1개
```

## 6. 메뉴 기능 보존 체크리스트

배경 1장 적용 후 반드시 아래를 확인한다.

```text
[기본]
- index.html 로드됨
- app.js 문법 오류 없음
- main.css 로드됨
- 새 배경이 캐시 없이 보임

[상단 메뉴]
- 음성 버튼 클릭 가능
- 낮/밤 버튼 클릭 가능
- 전체화면 버튼 클릭 가능

[하단 메뉴]
- 탐사 패널 열림/닫힘
- 도감 패널 열림/닫힘
- 미션 패널 열림/닫힘
- 카메라 패널 열림/닫힘

[충돌 방지]
- 패널 2개 이상 동시 노출 없음
- 팝업과 패널 겹침 없음
- UI가 배경 핵심 요소를 가리지 않음
- 물고기 클릭 영역이 메뉴와 겹치지 않음

[수족관]
- 물고기 유영 유지
- 물고기 이미지 깨짐 없음
- 광선/물결/입자 레이어가 배경과 자연스럽게 섞임
- 밤/저녁 모드에서도 물고기 식별 가능

[진단]
- PondangV30A1Debug.audit() 실행 가능
- audit problems가 있으면 보고
```

## 7. 사용자가 올릴 때의 응답 규칙

사용자가 이미지를 올리며 “웃물 낮 적용해”, “여울 저녁이야”처럼 말하면 다음 형식으로 처리한다.

```text
확인: 이번 이미지는 [존 이름] [낮/저녁] 배경으로 적용합니다.
대상 경로: [assets/bg/.../day-or-night.png]
이번 단계에서는 배경 1장만 교체하고, 메뉴와 낮/밤 전환 검증까지 진행합니다.
```

지칭이 불명확하면 적용하지 않고 이렇게 묻는다.

```text
이 이미지를 어느 슬롯에 넣을지 확인이 필요합니다.
가능한 슬롯: 웃물 낮, 웃물 저녁, 여울 낮, 여울 저녁, 잔여울 낮, 잔여울 저녁, 깊물 낮, 깊물 저녁, 물모이 낮, 물모이 저녁
```
