# 퐁당퐁당 V5 물고기 디자인 스타일 가이드 v1

## 1. 전체 방향

- 어린이 친화형 반실사 카툰을 기본으로 한다.
- 지나친 장난감 느낌보다 실제 생태 특징이 먼저 보이게 한다.
- 배경은 투명 전제를 유지한다.
- 수족관용 이미지는 자연스럽고 작게, 카드용 이미지는 더 선명하고 크게 만든다.
- PNG가 준비되면 PNG 우선, 없으면 SVG fallback을 사용한다.

## 2. 공통 형태

- 눈은 작고 또렷하게.
- 입은 과장하지 않는다.
- 비늘·측선·지느러미는 단순화하되 종 구분은 가능하게.
- 몸통에는 부드러운 명암을 준다.
- 물속에서는 진한 외곽선 금지.
- 카드에서는 외곽과 색을 조금 더 선명하게 허용한다.

## 3. 자산 구분

```text
assets/fish/{id}/
  swim.svg 또는 swim.png   # 수족관 유영용
  card.svg 또는 card.png   # 도감 카드용
  meta.json               # 생태·표시·동작 정보
```

## 4. 종별 디자인 우선순위

### 버들치
- 둥근 몸통.
- 연한 올리브빛.
- 흐릿한 가로 줄무늬.
- 웃물/여울 대표 친구.

### 피라미
- 버들치보다 길고 날렵한 실루엣.
- 등쪽은 푸른빛 또는 은빛.
- 배쪽은 밝게.
- 빠른 유영과 잦은 방향 전환이 느껴져야 한다.

### 쉬리
- 가늘고 긴 체형.
- 자갈 바닥과 어울리는 은은한 무늬.
- 빠른 직선 이동.

### 각시붕어
- 작고 납작하며 색이 예쁨.
- 수초 옆에서 카드 수집 욕구를 주는 형태.

## 5. 외래종/환상어종

- 외래종은 매력적인 수집 보상처럼 보이지 않게 한다.
- 외래종 카드는 경고·비교 학습 톤으로 처리한다.
- 환상어종은 반드시 `fantasy:true`와 “가상 어종입니다” 문구를 포함한다.

## 6. 적용 순서

1. 버들치 유지
2. 피라미 1종 추가
3. 쉬리 1종 추가
4. 각시붕어 1종 추가
5. 이후 도감 전용 후보 확장

## 7. 검수 기준

- 수족관에 한 번에 5종 이상 과밀 배치하지 않는다.
- 모바일 세로 화면에서 카드와 하단 메뉴가 겹치지 않는다.
- 이미지 실패 시 SVG fallback이 즉시 작동해야 한다.
- 새 어종 추가 후 기존 버들치 자산이 깨지면 실패다.
