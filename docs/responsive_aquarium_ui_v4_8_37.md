# 퐁당퐁당 v4.8.37 수족관/UI 반응형 최적화 기록

작성 기준: 2026-04-26
저장소: tantarus71-ctrl/pongdang-v5-web
대상 앱 파일: app_assets/index.html
추가 패치 파일: app_assets/patches/v4_8_37_responsive_aquarium_ui.css

## 1. 목적

v4.8.37의 목적은 핸드폰, 태블릿, PC에서 수족관이 화면의 중심으로 보이고, 하단 메뉴와 상단 컨트롤이 서로 겹치지 않도록 반응형 UI 기준을 보강하는 것이다.

핵심 기준:

- 수족관 시각 면적 최대화
- 하단 메뉴 4개 고정
- 아이들이 이해하기 쉬운 이모지/텍스트 구조
- 작은 휴대폰에서도 겹침 방지
- 태블릿/PC에서 중앙 전시형 수족관 유지
- 기존 fishLayer, sheetLayer, modalLayer와 충돌 최소화

## 2. 이번 작업 완료 내역

신규 파일을 추가했다.

```txt
app_assets/patches/v4_8_37_responsive_aquarium_ui.css
```

이 파일은 다음 영역을 보강한다.

1. 상단 제목 카드 압축
2. 구간/낮밤 컨트롤 칩형 정리
3. 수족관 카드형 시각 영역 확대
4. fishLayer 위치 재계산
5. 하단 메뉴 높이/간격/이모지 크기 최적화
6. 작은 휴대폰 보조문구 숨김
7. 태블릿 시네마형 배치
8. PC 중앙 전시형 배치
9. 가로 화면 저높이 대응

## 3. 적용 방법

app_assets/index.html의 `</head>` 바로 위에 다음 한 줄을 넣는다.

```html
<link rel="stylesheet" href="patches/v4_8_37_responsive_aquarium_ui.css">
```

주의:

- 기존 CSS를 삭제하지 않는다.
- 기존 v4.3.3 스타일 블록은 당장 제거하지 않는다.
- 새 CSS는 가장 마지막에 로드되어야 한다.
- 원본 전체 덮어쓰기는 금지한다.

## 4. 메뉴 설계 기준

하단 메뉴는 4개 고정이다.

| 버튼 | 권장 이모지 | 권장 라벨 | 기능 |
|---|---|---|---|
| 탐험 | 🫧 | 탐험 | 기본 수족관 탐색 |
| 도감 | 🐟 | 도감 | 민물고기 카드 목록 |
| 반짝 | ✨ | 반짝 | 희귀/상상 물고기 |
| 카메라 | 📷 | 카메라 | 카메라 모드 |

버튼 내부 권장 구조:

```html
<span class="navEmoji" aria-hidden="true">🫧</span>
<span class="navText">탐험</span>
<span class="navSub">물속보기</span>
```

작은 휴대폰에서는 `.navSub`가 자동으로 숨겨진다.

## 5. 반응형 기준

### 5-1. 작은 휴대폰

- 보조문구 숨김
- 메뉴 4개 한 줄 유지
- 수족관 최소 영역 확보
- 제목 카드 압축

### 5-2. 일반 휴대폰 세로형

- 수족관을 가장 크게 보여줌
- 하단 메뉴는 90px 전후
- 구간/낮밤 버튼은 칩형 스크롤

### 5-3. 태블릿

- 시네마형 수족관
- 좌우 여백 확대
- 메뉴와 컨트롤 중앙 정렬

### 5-4. PC

- 과도한 가로 확장을 막음
- 수족관 최대폭 1180px 기준
- 메뉴/컨트롤 최대폭 980px 기준

## 6. 현재 한계

현재 GitHub 도구는 app_assets/index.html의 부분 삽입 패치를 지원하지 않고, 전체 파일 교체 방식만 제공한다.

index.html은 큰 단일 HTML이며 도구 출력이 중간에서 잘릴 수 있으므로, 원본 전체를 덮어쓰는 방식은 위험하다.

따라서 이번 단계에서는 안전하게 독립 CSS 파일을 추가하고, 다음 단계에서 index.html 원본 전체를 확보한 뒤 링크 태그만 삽입하는 것이 맞다.
