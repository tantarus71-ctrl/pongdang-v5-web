# Pongdang4 Netlify Demo Deploy Guide

## Recommended Upload

Use the current deploy folder:

```text
deploy_netlify_v4_8_28
```

If you prefer ZIP upload, use:

```text
pongdang-v4.8.28-netlify-demo.zip
```

## Steps

1. Open `https://app.netlify.com/drop`.
2. Log in to Netlify.
3. Drag the `deploy_netlify_v4_8_28` folder into the drop area.
4. Wait for Netlify to finish the deploy.
5. Copy the generated `https://...netlify.app` URL.
6. Open the URL and confirm the aquarium demo loads.
7. Use that URL for the QR code.

## If The Root URL Does Not Open

Try this direct app path:

```text
/app_assets/index.html
```

Example:

```text
https://your-site-name.netlify.app/app_assets/index.html
```
